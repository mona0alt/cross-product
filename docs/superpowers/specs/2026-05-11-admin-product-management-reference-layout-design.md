# 商品管理页参考布局设计规格

日期：2026-05-11

## 目标

将后台 `/admin/products` 的主内容区调整为 `docs/design` 参考实现的高密度企业后台布局。范围仅限商品管理页，不替换全局后台侧边栏、登录、多语言和上传能力。

## 布局

- 页面顶部使用紧凑工具栏：标题、搜索框、导出按钮、新增商品入口。
- 主工作区采用左右结构：
  - 左侧为商品表格，展示商品、类别、状态、价格/评分、语言完成度和操作。
  - 右侧为固定宽度编辑抽屉，展示当前选中商品的图片、基础信息、多语言内容摘要、可见/推荐设置和保存入口。
- 保留审核能力：表格中的“编辑/审核”按钮切换右侧抽屉选中项，不再默认弹出大模态。
- 手动新增作为明确入口跳转到 `/admin/products/new`，不再作为商品管理页内的主 tab。

## 视觉

- 使用参考图的企业后台风格：浅灰背景、白色面板、8px 左右圆角、细边框、紧凑表格行。
- 主操作使用现有后台蓝/青色强调色，避免引入外部字体或 Material Symbols。
- 用 lucide 图标替代参考实现中的 Material Icons。

## 数据与行为

- 当前页面继续使用 `mockBackoffice.products` 驱动，保持现有审核数据结构。
- 默认选中第一条商品；点击表格行或编辑按钮更新右侧抽屉。
- 搜索框第一阶段仅作为 UI 控件，不引入筛选逻辑。
- 新增商品按钮跳转 `/admin/products/new`，编辑详情页仍保留 `/admin/products/[id]` 后续可接入真实产品列表。

## 测试

- 更新 `ProductCenter` 单元测试，验证参考布局关键结构：搜索框、商品目录/活跃商品面包屑、商品表格、右侧编辑商品抽屉、产品媒体、保存更改、新增商品入口。
- 更新后台页面集成测试，验证 `/admin/products` 渲染新布局文案。
