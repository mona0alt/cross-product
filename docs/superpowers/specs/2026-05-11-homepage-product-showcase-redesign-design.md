# 首页商品展示与顶部导航重设计规格

日期：2026-05-11

## 背景

本次设计基于 `docs/design` 的品牌化首页布局，并参考 UBTECH AI Education 页面的蓝色科技视觉体系。范围从首页商品展示扩展到顶部导航，因为导航需要与首页首屏和商品展示形成一致的品牌体验。

目标不是复刻原参考图的奶油/粉色轻奢风，而是转为白底、科技蓝、高端机器人品牌感，并减少大面积留白，让首页更聚焦商品展示。

## 目标

- 将首页从偏电商促销布局调整为高端机器人品牌展示首页。
- 保留必要的商品入口能力：分类导航、系列产品入口、产品图片矩阵、社交媒体卡片。
- 顶部导航去除搜索框，降低电商平台感。
- 引入 UBTECH 风格的白底科技蓝视觉，但首屏可以使用更强的蓝色旗舰渐变提升品牌记忆点。
- 保持页面信息密度适中，避免参考图那种过大的留白。

## 非目标

- 不重做商品列表页和商品详情页。
- 不引入应用场景或工程能力内容矩阵。
- 不新增搜索功能入口。
- 不改变后台数据模型。
- 不改变多语言架构，只复用现有字典和数据结构。

## 页面结构

首页推荐结构如下：

1. 顶部导航
2. 蓝色品牌首屏
3. 系列产品四卡片
4. 更多产品图片矩阵
5. 社交媒体卡片区
6. 保留现有页脚

## 顶部导航设计

导航保留现有功能能力，但调整视觉和信息层级。

保留内容：

- Logo
- 分类导航及桌面下拉菜单
- 移动端菜单
- 语言切换
- WhatsApp 或电话入口
- Portal 入口
- Inquire/询盘 CTA

移除内容：

- 桌面搜索框
- 移动端搜索框
- 黑色电商顶栏视觉

视觉方向：

- 顶部信息条使用浅蓝底，例如 `#f0f6fd`。
- 主导航使用白底、细蓝灰边框。
- 主导航文字使用深蓝，例如 `#123b73`。
- hover、当前态、重点 CTA 使用科技蓝，例如 `#1d7eea`。
- 下拉菜单保持白底，子分类图片卡片使用浅蓝描边和轻阴影。

响应式：

- 桌面端展示横向分类导航。
- 移动端保留汉堡菜单。
- 移动端菜单不显示搜索框。

## 蓝色品牌首屏

首屏用于建立高端机器人品牌印象。

布局：

- 全宽蓝色品牌区域。
- 左侧为短 eyebrow、标题、简短描述、两个 CTA。
- 右侧展示主视觉图，优先使用现有 banner 或机器人产品图。
- 轮播指示器可保留，但样式改为白色/浅蓝。

视觉：

- 背景使用深蓝到科技蓝渐变，例如 `#08275a -> #0f63ce -> #68b9ff`。
- CTA 主按钮使用白底深蓝字或科技蓝按钮。
- 次按钮使用白色描边。
- 文案保持简洁，不做大段说明。

数据：

- 继续使用 `getHomepagePayload(locale)` 返回的 `banners`。
- 如果有 banner 图片，图片作为主视觉或背景图。
- 如果没有 banner，显示蓝色渐变兜底。

## 系列产品四卡片

该模块对应参考图中的“系列产品”，但更紧凑。

布局：

- 居中标题。
- 桌面四列。
- 平板两列。
- 移动端单列或横向滑动，依据现有实现成本选择。

内容：

- 使用 `featuredCategories` 或现有分类组。
- 每张卡片展示分类图片、分类名称、英文/辅助标签。
- 点击进入对应分类或商品列表筛选页。

视觉：

- 卡片白底或浅蓝底。
- 圆角不超过 `12px`。
- 图片区域保持统一比例。
- hover 使用轻微上移、蓝色描边或阴影。

## 更多产品图片矩阵

本模块替代原先讨论的应用场景/工程能力 bento 区，只展示更多产品图片。

布局：

- 区块标题为“更多产品图片”或对应多语言文案。
- 右侧提供 `VIEW ALL` 或查看全部入口，跳转商品列表页。
- 桌面使用 1 张大图 + 4 张小图的 bento 矩阵。
- 移动端改为两列或单列卡片，避免图片过小。

内容：

- 优先使用 `recommendedProducts` 的前 5 个产品图片。
- 第一张作为大图。
- 其余四张作为小图。
- 点击每张图片进入对应商品详情页。
- 如果产品不足 5 个，按现有产品数量自适应，不展示空占位。

视觉：

- 背景使用浅蓝灰 `#f6f9fd`。
- 卡片白底，蓝灰描边。
- 大图使用更明显的轻阴影。
- 不加入应用场景文案。

## 社交媒体卡片区

保留社交媒体模块，并与新蓝色品牌体系一致。

布局：

- 标题区包含 eyebrow 和标题。
- 桌面四张竖向卡片。
- 保留左右切换按钮。
- 移动端可横向滚动或两列布局。

内容：

- 继续复用现有 `SocialShowcase` 的 tab 和图片资源，或简化为固定四张社媒内容卡。
- 卡片可显示平台标签，例如 TikTok、Instagram、YouTube、Facebook。
- 卡片以图片为主，少量标题覆盖在底部。

视觉：

- 背景以白底为主，减少厚重卡片装饰。
- 卡片圆角约 `12px`。
- 覆盖层使用蓝色/深色渐变，确保文字可读。
- 左右切换按钮使用圆形蓝色描边或蓝色填充。

## 组件与数据边界

建议调整的组件：

- `src/components/storefront/header.tsx`
- `src/components/storefront/banner-carousel.tsx`
- `src/components/storefront/product-card.tsx`
- `src/components/storefront/product-carousel.tsx`
- `src/components/storefront/catalog-carousel.tsx`
- `src/components/storefront/social-showcase.tsx`
- `src/app/[locale]/page.tsx`
- `src/app/globals.css`

可能新增组件：

- `HomepageCategoryGrid`
- `HomepageProductMatrix`

如果现有组件改动会让职责过宽，优先新增首页专用组件，避免破坏列表页和轮播页复用场景。

数据来源：

- `payload.banners`
- `payload.featuredCategories`
- `payload.recommendedProducts`
- `Storefront` 字典文案

不需要新增 API 或数据库字段。

## 样式系统

建议新增或替换前台 CSS 变量：

- `--mk-bg: #ffffff`
- `--mk-bg-muted: #f6f9fd`
- `--mk-surface: #ffffff`
- `--mk-border: #d8e6f6`
- `--mk-border-strong: #9cc9f6`
- `--mk-text: #0b1f3a`
- `--mk-text-muted: #54708f`
- `--mk-accent: #1d7eea`
- `--mk-accent-dark: #123b73`
- `--mk-highlight: #0f63ce`

整体避免大面积单一深蓝。深蓝主要用于首屏、标题和 CTA，页面主体以白色和浅蓝灰承载。

## 可访问性与响应式要求

- CTA、导航链接、下拉菜单需要保留键盘可访问性。
- 图片必须有合理 `alt`，装饰图可为空。
- 蓝色背景上的文字对比度必须足够。
- 导航在移动端不应出现横向溢出。
- 图片矩阵在移动端不能压缩到难以识别。

## 测试与验收

手动验收：

- 首页桌面端导航无搜索框。
- 分类导航和下拉菜单仍可访问。
- 语言切换、WhatsApp/Portal、询盘入口仍可用。
- 首页依次展示蓝色首屏、系列产品、更多产品图片、社交媒体卡片。
- 产品图片矩阵点击进入详情页或商品列表。
- 页面在移动端无重叠、无横向滚动。

自动检查：

- 运行现有 lint/test 命令。
- 如已有前台渲染测试，补充首页结构测试。
- 如没有合适测试，至少添加组件级测试覆盖产品不足 5 个时的矩阵渲染。

## 已确认决策

- 视觉参考 UBTECH AI Education 的蓝色体系。
- 采用更高端的蓝色品牌感，但减少留白。
- 顶部导航需要纳入本次调整。
- 去除搜索框。
- 内容矩阵只放产品图片，不放应用场景。
- 社交媒体卡片需要展示。
